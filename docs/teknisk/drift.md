# Systemdrift

Runbook = konkrete operasjonelle steg for å løse eller undersøke et spesifikt problem. Inneholder SQL-spørringer, kommandoer, feilmeldinger og nøyaktig fremgangsmåte.

Playbook = mer overordnet håndtering av en type hendelser. Beskriver symptomer, beslutningspunkter, alternativer, eskalering og hvilke runbooks som skal brukes.
